## Part 2: Explain the purpose of the devices
a. Based on your studies so far, explain the client-server model. Perform an internet search if needed.
```
The client-server architecture is where the server runs software(s) running on different ports that avail varying services to a client. An example is a local DNS server in an organization, where the laptops do not need to install any software to perform address resolution, they simply send their request(s) to the server which runs the DNS and the resolution is done on their behalf. Basically, the client connects to the server via a port to access the services the server is providing.
```
b. List 2 functions of intermediary devices.
```
1. Regenerate and retransmit network signals.
2. Maintain routing information.
3. Inform devices of errors and communication failures.
4. Direct data on new routes in case of link failures.
5. Quality of Service
6. Permit or deny the flow of traffic.
```
c. List at least 2 criteria for choosing a network media type
```
1. Cost of the media and cost of the installation.
2. Maximum distance covered.
3. Installation environment.
4. Amount of data and transmission speed.
```

# Part 3: Compare and contrast LANs and WANs
a. Explain the difference between a LAN and a WAN. Give examples of each.
```
A LAN connects devices over a small geographical area e.g. a home or small business network, while a WAN covers a much larger geographic are e.g. between continents
```
